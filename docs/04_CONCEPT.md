## 2. 후보

### A. 큐브 머지 팩토리 (최종 이름 *Merge Cube Factory*) — 협동 합치기 타이쿤
- 자기 섬(플롯)에서 드로퍼가 떨어뜨린 코어 큐브를 **물리로 합쳐** 등급을 올리고, 큐브가 진열대에서 돈을 번다.
- 상위 큐브는 "부화 코어" → 실시간 타이머 후 희귀 변이 큐브. 친구와 같은 공장 협동, 도감, 시즌 패스.
- Cubika의 합치기 로직·연출·검증·배틀패스 재사용.

### B. 협동 서바이벌 호러 (밤 생존형)
- 4인 협동, 밤마다 강해지는 위협, 거점 강화. 18+·co-play 매우 강함.
- 맵·몬스터·애니메이션 에셋과 레벨 디자인 부담이 큼. AI 자동 테스트 어려움(공포 연출 품질 판단).

### C. 물리 쌓기 파티 게임 (라운드형 8인)
- Cubika 쌓기를 멀티 경쟁으로. 짧은 라운드, 클립 바이럴 가능.
- 라운드 게임은 D8-28 재방문 동기가 약하고 수익 상품 폭이 좁다.

## 4. 1순위: A. 큐브 머지 팩토리

**한 줄:** "떨어뜨리고, 합치고, 부화시켜라 — 친구와 함께 세계 최대의 큐브 공장을."

차별점
1. **물리 합치기의 손맛**: 대부분 타이쿤은 버튼·컨베이어 자동. 우리는 Cubika에서 다듬은 hit-stop·섬광·파편·카메라 흔들림.
2. **협동 공장**: 친구가 같은 플롯에 들어오면 드로퍼 수·합치기 콤보 공유 → co-play 신호.
3. **실시간 부화 + 도감**: 재방문 이유. 변이(금/무지개/유리/네온…)로 같은 콘텐츠 반복 소비.
4. **자체 IP**: 큐브 캐릭터(눈 달린 큐브, Cubika 픽셀 큐브의 3D화). 밈 IP 없음.

Phase 2 옵션 (출시 지표 확인 후 결정)
- **침공(Heist) 이벤트**: 주말 한정, 다른 플롯의 진열 큐브를 "빌려오기" — 훔치기·방어 장르 수요 흡수. 보호막·잠금 시간으로 피해 상한.

> **최종 (2026-10-17):** 후보를 10개로 넓혀(12) 상위 3개를 시뮬레이션으로 비교(13)한 결과 **A+ (머지 팩토리 + 코어 농장)** 확정. 사용자가 컨셉 선정을 위임함(DECISIONS).
