## 4. 히트작 공통 패턴 (설계에 반영할 것)

1. **첫 1분 안에 보상이 터진다** — 들어오자마자 돈/펫/합치기. (RFY의 "첫 플레이 이탈률 <60초" 신호와 직결, 02 문서)
2. **실시간 타이머로 재방문** — 작물 성장, 알 부화, 로테이션 상점, 오프라인 수익. (Play days per user D2-7/D8-28)
3. **다른 플레이어가 화면에 있다** — 훔치기·거래·구경·자랑. (Intentional co-play days)
4. **주간 업데이트 + 관리자 이벤트** — Steal a Brainrot의 생존 이유는 "주간 업데이트 44회" [S17].
5. **수집 도감 + 희귀 변이** — 금색/무지개 등 변이로 같은 콘텐츠를 여러 번 소비.
6. **과금은 시간 단축·편의·자랑** — 2배 수익, 자동화, 슬롯 확장, 한정 꾸미기.

## 6. 결론 → 04 컨셉 선정의 입력

- **노릴 자리**: 타이쿤/시뮬(최대 수요) × **독창 IP** × 협동(co-play) × 실시간 재방문 루프 × 18+도 납득할 깊이.
- **피할 자리**: 밈 복제, 순수 오비, 단발 바이럴.
- 우리 강점: Cubika에서 검증된 **물리 합치기 손맛·연출(hit-stop, 섬광, 파편)**, 서버 검증, 배틀패스 진행 시스템.
