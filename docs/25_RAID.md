## 1. 보스 레이드
| 단계 | 시간 | 내용 |
|---|---|---|
| 초대 | 서버 시작 4분 뒤, 그다음 끝날 때마다 12분 뒤 | 모두에게 JOIN / NO THANKS 창 (20초). 공장이 로드된 사람만 |
| JOIN | 누르는 즉시 | 창이 닫히고 **광장 위 하늘 전장**(높이 260)으로 이동, 배트를 쥐고 대기("FIGHT STARTS IN n") |
| 전투 | 90초 | 공장이 로드된 사람이 **모두 답하면**(참여·거절) **마지막 답 3초 뒤** 바로 시작, 아니면 초대 시간이 끝날 때. 초대 중에 들어온 사람도 남은 시간이 있으면 창이 뜬다(초대 번호). 늦게 참여는 없음(사용자) |
| 결과 | 6초 | 보상 창 → 각자 공장으로 |

- **전장**: 반지름 44 떠 있는 섬(보라 바닥·빛나는 테·기둥 8개). 둘레에 보이지 않는 울타리가 있어 밀려나도 떨어지지 않는다. 그래도 떨어지거나 리스폰으로 집에 가면 전장 가장자리로 되돌린다. 참여하지 않은 사람은 옮기지 않는다.
- **보스 체력 = 타수**: `40 × 인원^0.8` → 1명 40, 2명 70, 4명 121, 8명 211 (2배 인원 = 1.74배 체력). 2026-10-21 리뷰: 0.6이면 8~20명이 5~25초에 잡아 패턴을 0~2번밖에 못 봄.
- **분노**: 체력이 절반 아래면 "<보스> IS ENRAGED!" → 패턴 간격 4.5 → 3초. 첫 패턴은 전투 1.5초 뒤.
- **타격**: 한 대 1, **크리티컬 2**. 간격은 **각자 배트 SPEED 쿨다운**(0레벨 0.9초 → 10레벨 0.39초). 사거리는 수평 11 + 보스 반지름, 높이 차 보스 반지름 + 8 (덮치기로 뜬 보스·날기 핵 막기). 전장 바닥보다 40 넘게 떠 있으면 가장자리로 되돌림.
- **누르고 있으면 계속 휘두름** (어디서나, 2026-10-21 사용자 "계속 눌러도 1번만"): 배트를 든 채 마우스·게임패드를 누른 채로(도구 Activated/Deactivated), 휴대폰은 SWING 버튼을 누른 채로. 간격은 탭과 같은 쿨다운. 레이드 경직 중엔 멈추고 SWING이 회색. Studio 확인: 3초 누름 → 4번(쿨다운 0.9초).
- **크리티컬 확률**: 기본 5% + 장착 배트 스킨: 나무 +1, 생선 +2, 바게트 +3, 네온·프라이팬 +4, 지팡이·골드 +5, 크리스탈 +6, 치킨 +7, 해머 +8, 레인보우 +10 (%p). 크리티컬이면 화면에 "CRIT! x2".
- **패턴** (번갈아, 사이 4.5초): 보스마다 다름(아래 표). 맞으면 밀려나고(수평 38, 위 26 × (1 − 넉백 저항)) **2.5초 × (1 − 0.6 × 저항)** 동안 못 때림 ("STUNNED!"). 2026-10-21 리뷰: 1.5초면 맞는 것과 피하는 것의 손해가 비슷했음.
- **목숨 5개** (2026-10-21 사용자 "5번 이상 맞으면 그 보스전 실패"): 패턴에 5번 맞으면 "YOU'RE OUT!" → 1.5초 뒤 집으로, 그 판은 실패. 남은 목숨은 **자기 머리 위 하트**(♥ 빨강 = 남음, 회색 = 잃음, 모두에게 보임, `RaidLives` BillboardGui). 맞을 때 "STUNNED! ♥♥♥ LEFT". 리스폰하면 하트를 다시 단다.
- Studio 확인(2026-10-21, 1인): 첫 피격에 ♥♥♥♥ + 회색 1, 5번째에 out → 집(y=4), 혼자라 바로 실패·보상 0.
- **점프 유예**: 충격파·레이저가 지나갈 때 0.2초 안에 떠 있었으면 피한 것으로 (모바일 지연).
- **보스 로테이션** (사용자 "보스 3~4개, 조금씩 다른 패턴, 로테이션"): 레이드마다 다음 보스 차례(`Raid.bossAt(n)`), 서버마다 시작 보스는 무작위. 초대 창 제목 "BOSS RAID: <이름>!"과 색·설명이 보스마다 다르다.

## 7. 광장 발판 (`server/Stations`, `client/Stations`)
- 사용자 "버튼이 너무 많아질 것 같으면 중앙 광장에 오브젝트 + 비컨 조합으로 위에 올라갈 때만 탭". "펫 가챠 등 다른 기능도 이런 식으로".

## 8. 큐브 인벤토리 (`client/CubeInventory`)
- 오른쪽 가장자리 작은 `CUBES` 버튼 → 위젯(휴대폰은 오른쪽 버튼 줄 왼쪽에 떠서 특가 버튼을 가리지 않음)(트레이의 높은 등급 8개와 개수, 2개 이상 = 짝이 있어 초록) → 위젯을 누르면 전체 창(1~40등급 칸, 없는 등급은 흐리게).
- **눈 아이콘 = 트레이에서 찾기** (2026-10-21 사용자 "상위 큐브가 합쳐질 수 있는데 다른 큐브가 많아 찾기 힘들 때"): 위젯의 색 네모(눈)를 누르면 내 트레이에서 그 등급만 초록 테두리(SelectionBox), 나머지는 반투명(LocalTransparencyModifier 0.85, 내 화면에서만). 다시 누르면 끔. 전체 창의 칸을 눌러도 창이 닫히고 그 등급 강조. 그 등급이 트레이에서 사라지거나 위젯·창을 모두 닫으면 꺼짐. 0.25초마다 새 큐브에 다시 적용.
- 흐린 큐브는 등급 숫자(SurfaceGui)·변이 이름표·빛·입자·변이 테두리도 끄고(FocusOff 표시, 원래 꺼진 것은 안 켬), 다른 등급의 합치기·착지 연출은 작은 소리만(찾는 등급끼리 합친 것·새 최고 등급은 그대로, `Player.CubeFocus` 속성) — 사용자 "숫자나 머지 이펙트도 줄이지 않으면 잘 안 보임".
- **유리 벽**: Roblox는 Glass 재질 뒤의 반투명 물체를 그리지 않아, 벽 너머로 보면 강조한 큐브만 보였다(사용자 제보). 강조 중엔 내 공장 Glass 벽을 내 화면에서만 SmoothPlastic으로 바꾸고 끄면 되돌림.
- Studio 확인(2026-10-21): T8 눈 → 10개 중 9개 반투명·1개 테두리, 다시 누르면 모두 원래대로.
- 서버 상태에 `trayTiers = { {tier, count}, ... }`(높은 등급부터).

## 9. 자석 (`Config.magnetInterval/magnetRest`)
- 높은 등급일수록 자석이 조금 세다: 뛰는 간격 0.8초 → T40 0.4초, "멈췄다"고 보는 속도 1.5 → T40 3.4(덜 멈춰도 끌림).
- 큰 큐브가 작은 큐브를 밀어내는 힘을 키우는 안은 쓰지 않았다(트레이가 더 어수선해짐).

## 10. 특수 큐브 꾸미기 (`shared/VariantDecor`)
| 변이 | 꾸미기 |
|---|---|
| NEON | 가로줄 네온 셔터 선글라스 (분홍 테 + 청록 줄 3개 × 2알 + 다리) |
| RAINBOW | 둘레를 기울어진 궤도로 도는 무지개 꼬리 (조각 20개, 머리 흰색 → 꼬리로 갈수록 가늘고 흐려짐) |
| GALAXY | 궤도를 도는 성운 구름 3개(보라·분홍·파랑) + 별 5개 |
| COSMIC | 더 크고 두 겹(서로 반대로 기울고 반대로 도는) 성운 8개 + 큰 별 6개 |
| DIVINE | 머리 위 금빛 **크리스탈 헤일로** (둥실거리며 돎) |
- 입자(ParticleEmitter·Trail)는 도감 ViewportFrame에 안 그려지므로 모두 파트·메시·Decal로 만든다 → **공장과 도감에서 같은 모양**. 도감은 큰 꾸미기 칸만 카메라를 뒤로 뺀다.
- 에셋 검색(Studio MCP, 2026-10-20): 헤일로는 Creator Store "The Crystal Halo" (1688249565, 무료, 스크립트 없음, 메시 1688249536)를 SpecialMesh로 씀. 선글라스는 쓸 만한 무료 메시가 없어(다른 게임 아이템 재업로드뿐 → 쓰지 않음) 파트로 만들었다. 스토어 성운 사진은 배경이 꽉 차 구름으로 못 써서 Roblox 기본 입자 그림(`rbxasset://textures/particles/smoke_main.dds`)을 Decal로 씀.
- 서버는 용접만 하고(이름 `VariantDeco`), 돌리기·둥실은 클라 Fx가 한다(서버 비용 0, 150 studs 밖은 안 돌림).

## 11. 남은 점
