# 05. 게임 디자인 문서 — 큐브 머지 팩토리 *Merge Cube Factory*

> 04에서 1순위로 선정된 컨셉의 설계. 사용자 확정 전까지 **초안**이며 수치는 모두 `Config`로 뺄 튜닝값이다.
> 수치 표기: `$` = 게임 내 현금(Cash), `◆` = 젬(프리미엄 재화, 무료 획득 가능).

## 1. 판타지와 톤
- "작은 공장주가 되어 큐브 생명체를 떨어뜨리고 합쳐, 섬을 거대한 공장으로 키운다."
- 밝은 로우폴리 + 큐브 캐릭터(눈·표정). 성숙도 목표 **Mild**(02).
- 아바타 **R15** 사용(03: DevEx 가산 자격). 캐릭터는 플롯 위를 걸어다니며 큐브를 들고 던질 수 있다.

## 2. 핵심 루프

```
 [드롭] 드로퍼/손으로 큐브 투하 ──▶ [합치기] 같은 등급 접촉 → 등급+1 (물리, 연출)
      ▲                                      │
      │                                      ▼
 [업그레이드] 드로퍼 속도·등급·슬롯 ◀── [수입] 트레이 위 큐브가 초당 $ 생산
                                             │
                                  고등급 합치기 → [부화 코어] 실시간 타이머
                                             ▼
                                  [변이 큐브] 진열대 배수 + 도감 등록
 메타: 리버스(환생) → 영구 배수 + 새 바이옴 / 시즌 패스 / 일일 퀘스트 / 협동
```

## 3. 첫 세션 설계 (이탈률 신호 대응)

| 시점 | 일어나는 일 | 목표 |
|---|---|---|
| 0~5초 | 내 섬에 스폰, 드로퍼 1대가 이미 큐브를 떨어뜨리는 중, 화살표가 큐브를 가리킴 | 로딩 직후 움직임 |
| ~10초 | 큐브를 들어 같은 큐브 위로 떨어뜨림 → **첫 합치기**(풀 연출) | 손맛 |
| ~30초 | $10 모임 → "드로퍼 속도 업" 버튼 강조 → **첫 구매** | 성장감 |
| ~90초 | 등급 4 도달 → 새 드로퍼 해금 | |
| ~3분 | 첫 부화 코어(1분짜리 튜토리얼 타이머) → 변이 큐브 획득, 도감 첫 칸 | 수집 시작 |
| ~5분 | 일일 퀘스트 3개 소개, "친구 초대하면 팀워크 보너스" 안내 | 재방문·co-play |
| 종료 시 | "코어 부화 완료까지 18분 / 오프라인 수익 최대 4시간" 안내 | D1 재방문 |

- 2026-10-20 구현: 첫 접속(리버스 0·SPEED 0)에만 손가락 안내 두 단계 — DROP 버튼 "TAP DROP!"(3번 누르거나 20초) → 돈이 모이면 1번 드로퍼 위 "BUY SPEED!"(`client/Tutorial.luau`). R$ 반짝 특가 버튼은 첫 리버스 뒤부터 보인다.

## 4. 시스템

### 4.1 큐브 등급
- 12단계(Cubika 계승). 한 변 크기·수입·합치기 점수는 Cubika SPEC 2장 곡선을 재사용(단계마다 약 2.3배).
- 수입: `income(t) = BASE_INCOME × INCOME_GROWTH^(t-1)` $/초, 초안 `BASE_INCOME = 1`, `INCOME_GROWTH = 2.4`.
- 트레이 용량(플롯당 물리 큐브 수) 초안 40 — 넘치면 가장 낮은 등급이 자동 판매. (성능 상한, 06)

### 4.2 드로퍼
| 속성 | 시작 | 업그레이드 끝 |
|---|---|---|
| 투하 간격 | 2.0초 | 0.5초 |
| 투하 등급 | 1 | 6 (리버스 단계에 따라 상한 증가) |
| 슬롯 | 2 | 8 (+2 패스) |
- 비용 곡선: `game/src/merge/shared/Economy.luau`가 기준(13 §5). 단계별 지수 곡선 × 보정 배율 k(2.42e4)를 **처음 몇 단계에 걸쳐 서서히 적용(ramp)** — 첫 업그레이드 $10은 3초 만에 산다. 시뮬레이션에서 k를 한꺼번에 곱하면 첫 구매가 85초로 늦어졌다(13 §2 #3).

### 4.3 합치기
- 접촉한 같은 등급 2개 → 아래쪽 큐브가 등급+1, 위쪽 소멸(Cubika 규칙).
- 1초 안 연속 합치기 = 콤보, 수입 보너스 1+0.5×(콤보-1), 최대 ×3.
- 연출: Cubika `Fx.luau` 이식(hit-stop, 흰 섬광, 충격파, 파편, 단계≥7 별, 화면 흔들림).
- 판정은 **서버**(06). 클라이언트는 연출만.

### 4.4 부화 코어와 변이
- **코어 농장 = 두 번째 성장 축(A+, 13 §5).** 등급 5 이상 합치기 시 25% 확률로 "코어" 생성 → 대기열(최대 6) → 부화대(시작 2, 최대 12)에서 실시간 타이머.
- 부화 보상 = 영구 수입 보너스 + 즉시 현금(시작 시점 초당 수입 × 타이머 × 0.6). 대기열이 가득 차면 새 코어는 초당 수입 5초치로 자동 판매.
  | 등급 | 코어 | 타이머 | 영구 보너스 |
  |---|---|---|---|
  | 5 | Pebble | 2분 | +0.2% |
  | 6 | Shard | 5분 | +0.3% |
  | 7 | Crystal | 10분 | +0.5% |
  | 8 | Gem | 20분 | +0.8% |
  | 9 | Prism | 45분 | +1.2% |
  | 10 | Nova | 1.5시간 | +2% |
  | 11 | Star | 3시간 | +3% |
  | 12 | Cosmic | 8시간 | +6% |
- 짧은 타이머가 많아 하루 재방문 이유가 A 4.1 → A+ 7.2로 늘었다(13 §3.3).
- **CORES 패널 화면 (2026-10-19, `client/init.client` renderCores)**
  - 코어 그림은 **등급마다 다르다**: `CoreT5` … `CoreT40` (`tools/make_ui_icons.py`, "코어별 이미지 전부 다르게"). 아이콘이 없으면 띠 그림 `Core1`~`Core8`, 그것도 없으면 `Cores`. 예전 번개 균열 두 줄 디자인은 모더레이션에서 혐오 상징 닮은꼴로 거절돼 네온 코어로 다시 그렸다.
  - 아이콘 오른쪽 아래 작은 배지: 부화 중이면 **시계(Clock)**, 다 되면 **체크(Check)** + 흔들림.
  - **다 된 코어는 목록 맨 위로** 정렬(다 됨 → 부화 중 → 빈 칸). **카드 어디를 눌러도(알 아이콘 포함) 받기**. 받으면 카드가 바로 숨고 다음 다 된 코어가 같은 자리로 올라와, 한 자리만 계속 눌러 다 받을 수 있다("부화된 코어가 리스트 상단으로, 제자리 클릭으로 부화"). 두 번 눌러도 한 번만 받고, 서버가 거절하면 카드를 되돌린다.
  - 상태는 1초마다 오지만 **구성(코어 등급·다 됨 여부·보상·대기 수)이 바뀔 때만 다시 만든다**. 같으면 진행 막대와 남은 시간만 고친다 — 매번 다시 만들면 누르는 도중 버튼이 바뀌어 클릭이 씹혔다.
- ~~부화 결과 = 변이 큐브~~ → **변경(2026-10-18, docs/16)**: 변이는 합치기·투하 때 무료 확률로 생긴다. Metallic ×1.5 / Neon ×3 / Rainbow ×8 / Galaxy ×25 / Cosmic ×70 / Divine ×200(2026-10-18 사다리 확장). 합치면 한 단계 약해져 이어지고, 같은 변이끼리는 융합(한 단계 위).
- **유료 상품은 확률을 사지 않는다**: Instant Hatch(시간 단축)만 판매. "Lucky Boost"는 PolicyService 유료 랜덤 허용 사용자에게만 노출하거나, 출시 버전에서는 빼는 것을 기본값으로 한다(02 §4-2).
- 도감: `MAX_TIER` × 4변이(지금 48칸). 첫 발견·발견 수 마일스톤마다 젬, 일정 발견 수에 꾸미기 해금(docs/16 §5~6). 영구 수입 보너스는 넣지 않았다(경제 영향을 변이 배수 하나로 묶음).

### 4.5 리버스(환생)
- 조건: 현금 `2e5 × 12^r × k` 지불(최대 5회, `Economy.rebirthCost`). 플롯 초기화, 영구 수입 배수 +50%, 새 바이옴 테마(초원 → 사막 → 얼음 → 화산 → 우주), 드로퍼 최대 등급 +1.
- 리버스 1회까지 약 45~60분 플레이 목표(하루 60분 상한 신호에 맞춤).

### 4.6 오프라인 수익
- 접속 종료 동안 수입의 **10%, 상한 4시간**(구독 6시간). 50% × 8시간이면 전체 수입의 83~95%가 방치에서 나와 접속할 이유가 사라졌다(13 §2 #2). 재접속 시 "받기" / "광고 보고 2배 받기"(Rewarded Video).
- 상한이 "자연스러운 멈춤 지점" 역할(02 §4-1).

### 4.7 협동(Teamwork)
- 서버 8플롯. 친구 플롯에 "도우러 가기" → 도우미가 떨어뜨린 큐브는 주인 플롯에 귀속, 도우미는 기여량의 30%를 자기 플롯 현금으로 받음.
- 같은 플롯에 2명 이상이면 팀워크 보너스 +20%(4명 +50%). → 2026-10-20: **친구끼리만, 양쪽 모두**(방문자도 받음), 초대 버튼 추가 (docs/25 §5).
- 사설 서버 저가 제공(03).
- 일일 퀘스트 중 1개는 협동 퀘스트("친구와 합치기 50회") — 강제는 아니며 솔로 대체 퀘스트 선택 가능.

### 4.8 진행·라이브옵스
- **엔드게임 이후가 필수:** 시뮬에서 hardcore는 17일에 엔드게임 도달(13 §4). D8-28 신호를 위해 도감·시즌·주간 변이가 출시 시점에 있어야 한다.
- 시즌 패스: Cubika `PROGRESSION.md` 재사용(경험치 레벨 50, 무료/패스 트랙, 골드 상점 → 여기서는 젬 상점).
- 일일: 퀘스트 3개(날짜 시드, 모든 서버 동일) + 접속 선물(3분마다 작은 선물, 15·30·45·60분 큰 선물, 무료 랜덤). docs/23_DAILY.md (2026-10-19 구현). 2026-10-20: 7일 출석(고정 보상), 퀘스트 목표가 리버스 수에 따라 커짐.
- 접속 중 가속 (2026-10-20, docs/25): 12분마다 **보스 레이드**(참여 묻기, 타수 기준, 보스 코인 → 영구 강화, 잡으면 서버 모두 x2 5분), 온라인 연속 보너스(최대 +50%), 피버 강화(20초·드로퍼 2배속), 콤보 현금, 광장 선물 상자, 접속 중 부화 2배.
- 공장 위에 주인 아바타 얼굴(헤드샷 BillboardGui, `rbxthumb://type=AvatarHeadShot`)을 띄운다(2026-10-19).
- 주간: 신규 변이 1종 또는 바이옴 장식 / 주말 이벤트(2배 부화 속도, 관리자 이벤트).

### 4.9 소셜·순위
- 서버 순위(leaderstats): 초당 수입, 리버스 수.
- 전 서버 랭킹 패널(2026-10-20): 최고 수입(버프 뺀 기본 수입) / 누적 합치기 / 리버스 3개 탭 + 상위 50 밖이어도 내 줄 고정.
- 전체 순위: 도감 완성률, 최고 단일 큐브(OrderedDataStore). 조작 방지는 서버 권한 경제로 해결(06).

## 5. UI (모바일 우선)
- 하단: 상점 / 업그레이드 / 도감 / 부화 / 패스. 우측: 일일 퀘스트 패널. 상단: $·◆·초당 수입.
- 모든 버튼은 엄지 영역, 최소 터치 44px 상당. PC는 단축키 보조. 콘솔은 Phase 2.
- Cubika 테마 토큰(UITheme) 재사용 후 색만 밝은 톤으로 교체.
- **화면 크기 맞춤 (2026-10-19, `Ui.fitScale`)**: UI는 1280×720 기준 단위로 만들고, ScreenGui의 UIScale = min(가로/1280, 세로/720) × 1.02(터치 0.91, 처음 1.3에서 "휴대폰 UI가 너무 크다"는 피드백으로 -30%, 2026-10-19), 단 세로 560 단위는 항상 들어가게 상한. 그래서 모니터 해상도가 달라도 UI가 화면에서 차지하는 비율이 같다. 예전 식(720/세로 × 0.85, 0.85~1.4)은 1080p·1440p에서 UI가 화면 대비 절반 이하로 작아지고, 휴대폰에선 1.4배로 넘쳤다.
- **휴대폰 배치 (2026-10-19, `Ui.isTouch`)**: 키보드 없는 터치 화면에선 아래 왼쪽·오른쪽 끝을 비운다(이동 스틱·점프 자리). UPGRADES·CORES·TOP·SHOP은 오른쪽 위로 옮긴다: 화면 가로 1500 단위 이상이면 한 줄, 좁으면(4:3 태블릿·옛 16:9 폰) 위 가운데 목표 막대와 겹치므로 2×2. 부화 남은 시간은 CORES 아래, 단기 버프 버튼은 그 아래. BAT 버튼은 DROP 왼쪽, DROP·STEAL·BAT은 Roblox 점프 버튼 왼쪽으로 민다.
- **휴대폰 패널·왼쪽 버튼 (2026-10-20)**: 패널은 화면 가운데에 화면 높이에 맞춰 키운다(UIScale `TouchScale`, 1~1.5배). 왼쪽 버튼 줄(도감·일일 선물·펫)은 높이 56·간격 28로 벌린다(PC는 40·6 그대로).
- **패널 바깥 누르면 닫기 (2026-10-20, 전 기기)**: 패널이 열린 동안 투명 전체 화면 버튼 `PanelBackdrop`(ZIndex 0, HUD 아래)을 깐다. HUD 버튼은 그대로 눌리고, 3D 화면 탭은 닫기만 하고 투하로 새지 않는다. 패널 Frame은 Active여도 아래 버튼으로 클릭이 새므로 누른 자리가 열린 패널 안이면 무시한다.
- **다음 목표 바 (2026-10-19, `client/GoalBar`)**: 위 가운데. 트레이 최고 등급 < 이번 리버스 천장이면 "MAKE T{n}", 천장이면 리버스 진행 막대(누르면 REBIRTH 탭), 리버스 끝이면 도감. 아래 줄에 할 수 있는 일(도감 보상·코어·강화·훔치기·변이 사냥)을 4초마다 돌려 보여 주고 누르면 해당 패널. docs/13 §9.4의 "천장에서 기다리는 시간"에 할 일이 보이게 하려는 것.
