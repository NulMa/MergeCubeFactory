# 29. AI 플레이어 (봇)

> 사용자 (2026-10-24): "플레이어 수가 미달이라면 ai 플레이어도 조금 넣어볼까, 공장 성장보다는(안하는건 아님) 훔치기나 지키기를 간헐적으로 시도하거나 맵을 돌아다니는 방향으로".
> 코드: `server/Bots.luau`, 설정 `Config.BOTS`, 훔치기 연결 `server/Steal.luau` (`setBots`, `botCandidates`, `botSteal`).

## 1. 규칙
| 항목 | 값 | 이유 |
|---|---|---|
| 몇 명 | 사람 + 봇 = `FILL_TO`(4)가 될 때까지, 최대 `MAX`(3). 사람 0명이면 0 | 혼자 들어온 서버도 훔치기·지키기가 일어나게 |
| 자리 | 빈 플롯만. 사람이 왔는데 빈 플롯이 없으면 봇 하나가 바로 나간다 (`Plots.claim` → evict) | 봇 때문에 사람이 튕기면 안 됨 |
| 표시 | 머리 위 `[BOT] 이름`, 표지판 `이름's Factory (Bot)`, 털림 알림 `이름 (Bot)` | 사람인 척하지 않는다. 봇은 `Players`에 없어서 접속자 수·랭킹·추천 지표에 안 들어간다 |
| 공장 | 드로퍼 2개 + 사람 트레이와 같은 접촉 합치기·자석 깡충(`Factory.botMerge`, 저장·보상 없음). 최고 등급 = 사람 최고 등급 평균 −`TOP_BELOW`(1), 절대 상한 `TOP_MAX`(26). 드롭 등급 = 사람 드로퍼 최고 등급 평균 −`DROP_BELOW`(2). 3초마다 다시 맞추고 상한을 넘는 큐브는 판다 | 2026-10-25 사용자: 중간값 −7 드롭 + 리버스 상한까지 합치기라 봇 큐브가 사람보다 높았다(봇만 털면 그만이거나, 봇은 털 등급이 안 나옴) |
| 훔치기 | 봇 하나당 `STEAL_EVERY`(90~180초)마다, 한 번에 봇 하나만 운반. 같은 사람은 `VICTIM_COOLDOWN`(5분) 뒤에 다시 | 가끔 일어나는 사건으로 |
| 훔치기 규칙 | 사람과 같다: 상위 2등급 보호, 봇 합치기 상한 이하, 운반 속도·시간 제한, 들고 가는 중 배트에 맞으면 돌려줌. 리버스 0회 사람은 털지 않는다 (`STEAL_NEWBIES=false`) | 첫 판 보호 (docs/22) |
| 고르기 | 훔칠 수 있는 목록에서 무작위 (가장 높은 것 아님) | 사람이 잃는 양을 줄이고 덜 뻔하게 |
| 지키기 | 봇 트레이를 털리면 `DEFEND_CHANCE`(75%)로 `DEFEND_DELAY`(1.5초) 뒤 쫓아간다. 도둑만 친다 (`Steal.batHit`의 only) | 지키기 연출, 아무나 때리지 않게 |
| 하는 일 | 광장 산책, 남의 공장 구경, 자기 트레이에서 배트질, 집 앞에서 쉬기 | 맵이 살아 보이게 |

## 2. 구현 메모
- 봇 = `Players:CreateHumanoidModelFromDescription`(R15, 피부·옷 색만). 서버가 물리 주인(`SetNetworkOwner(nil)`). 걷기·대기·낙하 애니메이션은 Roblox 기본 R15 애니메이션을 서버 Animator로 재생, 배트 스윙은 `AssetIds.Anims.BatSwing`.
- 길찾기: PathfindingService. 모래(Sand) 비용 40 — 플롯 사이 모래섬을 징검다리로 건너던 문제 (Studio 2026-10-24). 길이 없으면 직선으로 가지 않는다 (바다에 빠짐). 트레이는 벽이 있어서 점프 패드처럼 서버가 포물선 비행(`fly`)으로 드나든다.
- 트레이 안에서는 길찾기가 안 된다 → 행동마다 먼저 "트레이 안이면 나가기". 4초 넘게 몸통 높이 < 2.5(물)면 집으로 옮긴다.
- 대기(`pause`)·걷기는 털림(chase)이나 디버그 지시가 오면 바로 끝난다.
- Studio 확인: 봇 속성 `Doing` = 지금 하는 일. 디버그 `StudioDebug:Invoke("bots", player, n)`(봇 수 고정, -1 자동), `"steal"`(봇 하나가 지금 그 사람을 턴다, 촬영용).

## 3. Studio 확인 (2026-10-24, 1인)
- 봇 3명 생성·플롯 차지·걷기 애니메이션·배트 들기.
- 봇이 내 트레이에서 훔쳐 자기 공장까지 가져감 (운반 중 표시 `*`, 집 도착 시 확정).
- 내가 봇 트레이를 털자 봇이 쫓아와 패드로 트레이에 들어와 치고 큐브를 되찾음.
- 큐브를 든 봇을 내가 배트로 치자 바로 돌려받음 (hits 1).
- 아직: 8인 꽉 찬 서버에서 9번째 사람이 오면 봇이 비켜 주는 것 (실서버), 봇 여러 명이 동시에 도는 장시간 안정성.

## 4. 끄기
`Config.BOTS.ENABLED = false` (Studio 디버그 `bots 0`도 됨).

## 5. 고침 (2026-10-25)
- 봇 공장에 STEAL 버튼이 안 떴다: 클라이언트(`client/Steal` otherPlotHere)가 `OwnerUserId` 있는 플롯만 봤다 → `BotName` 플롯도 포함.
- 사람이 낮은 등급뿐이면 봇 생성이 `math.clamp` 오류로 실패하고 플롯만 봇 이름으로 남았다 → 클램프 수정, 기준 계산을 플롯 잡기 전으로, 실패는 warn.
- 봇 트레이 큐브가 안 움직였다 (사용자 "봇 트레이 안의 큐브는 안움직이는거같은데"): 멈춘 같은 등급 둘을 그 자리에서 지우고 새로 만들었다 → `Factory.botMerge`(사람과 같은 접촉 합치기 + 자석 깡충, 근처 사람에게 합치기 연출). 봇 공장 주기 0.5 → 0.2초. Studio: 15초에 16번 움직임, 합치기 2번.
