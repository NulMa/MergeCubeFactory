# 02. 플랫폼 규칙 — 노출·정책·금지 (2026-10-17 기준)

이 문서는 "무엇을 만들어야 노출되고, 무엇을 하면 잘리는가"의 기준이다. 공식 문서만 근거로 쓴다.

## 1. 추천 알고리즘 (Home "Recommended For You", RFY)

2026-06-15 개편 [S1]: 7일 → **28일** 관점, qPTR(qualified PTR) 제거 → **PTR + 첫 플레이 이탈률** 추가, 신호 목록과 우선순위 공개 [S2].

| 우선순위 | 신호 | 구간 | 우리 설계 대응 (05 GDD) |
|---|---|---|---|
| **최중요** | Play-through rate (노출 → 실제 플레이 비율) | — | 아이콘·썸네일·제목이 실제 게임과 일치, A/B (09) |
| **최중요** | 첫 플레이 이탈률 (**부정 신호**) | <60초, 61~180초 | 첫 10초 첫 합치기, 30초 첫 구매, 3분 첫 언락 |
| **최중요** | 사용자당 플레이 일수 | D1, D2-7, **D8-28** | 실시간 부화, 오프라인 수익, 일일 퀘스트, 주간 이벤트 |
| **최중요** | 사용자당 플레이 시간 (**하루 60분 상한**) | D1, D2-7, D8-28 | 하루 60분 넘는 그라인드는 신호상 가치 없음 → 짧고 자주 |
| 중요 | 의도적 동반 플레이 일수 (친구 join/초대/사설 서버) | 〃 | 협동 공장, 친구 보너스, 사설 서버 |
| 중요 | 사용자당 qualified play 세션 수 | 〃 | 세션 시작 보상(부화 완료 알림) |
| 중요 | 지출 일수 / 사용자당 Robux | 〃 | 소액 상시 상품 + 일일 딜 (03) |

알아둘 점 [S2]
- 신호는 **사용자당 평균**: 작은 게임도 몰입도가 높으면 불리하지 않다.
- 신호는 **RFY로 유기적으로 들어온 사용자 기준**. 광고(스폰서)로 온 사용자는 RFY 신호에서 제외, 광고가 RFY를 깎지는 않음.
- 신작은 28일 기다리지 않는다: 첫 세션(PTR·이탈) → D1 → D2-7 → D8-28 순으로 신호가 쌓인다.
- 노출이 커지면 일시적으로 PTR이 떨어지는 것은 정상.
- 경쟁작이 더 크게 개선되면 내 신호가 그대로여도 노출은 준다 → **주간 업데이트가 기본값**.
- 2026-07-29 "Deep play-through rate" 신호 추가 공지(초기 클릭 이후 지속 참여) [S4]. 정식 표 반영 여부는 다음 갱신 때 확인.

## 2. 노출이 제한되는 사유 [S2]

| 사유 | 예 | 우리 규칙 |
|---|---|---|
| 기프트/보상을 앞세움 | 제목 "Robux! Play now!" | 메타데이터에 Robux·무료 보상 표현 금지 |
| 메타데이터와 내용 불일치 | 공룡 썸네일인데 공룡 없음 | 썸네일은 **실제 게임 화면** 기반만 |
| 비독창 게임 | 기존 게임과 제목·비주얼·플레이스 파일이 매우 유사 | 템플릿/키트 통째 사용 금지, 자체 IP |
| 안전·커뮤니티 기준 위반 | — | 07의 정책 검사 단계 |

Creator Dashboard에 노출 제한 배너가 매일 갱신되어 표시된다 → 게시 후 매일 확인(09).

## 3. 연령·성숙도

| 라벨 | 접근 가능 [S7] |
|---|---|
| Minimal / Mild | Roblox Kids(5~8), Roblox Select(9~15), 일반 |
| Moderate | Roblox Select(9~15), 일반(16+) |
| Content May Vary | 연령 확인된 16+ |
| Restricted | ID 인증된 18+ |

- **Roblox Kids / Select 계정(2026-04)** [S8]: 게임이 이 계정들에 노출되려면 크리에이터가 **ID 인증 + 2단계 인증 + Roblox Plus 구독($4.99/월) 유지**, 그리고 16+ 사용자 반응·신고 실시간 평가를 통과해야 한다. 소셜 행아웃·자유 그리기·민감 주제 게임은 기본 제외.
  → 우리 게임은 **Mild 목표**, 크리에이터 인증 3종을 출시 전 체크리스트에 넣는다(10).
- 성숙도 설문은 게시 전 필수(미완료 시 공개 불가). 답은 게임 안 **가장 수위 높은** 콘텐츠 기준.

## 4. 금지·제한 패턴 (코드 리뷰 체크리스트로 사용)

1. **끝없는 피드 소비 보상** — "자연스러운 멈춤 지점 없이 연속 콘텐츠 소비를 보상"하는 구조는 어린 계정에 불허(2026-08, Steal An Egg 사건) [S15][S16].
   → 오프라인 수익은 **상한(예: 8시간)**, 세션 보상은 횟수 상한, 자동 재생 영상 없음.
2. **유료 랜덤 아이템** — Robux(또는 Robux로 산 것)로 무작위 보상을 얻는 기능은 `PolicyService`로 불허 사용자에게 차단 **의무** [S6]. 유료 아이템 거래·몰입형 광고도 PolicyService 확인.
   → 우리 설계는 **유료 랜덤 없음**(유료 상품은 전부 확정 보상). 무료 재화 뽑기만 허용.
3. **미성년 대상 압박 문구** — "지금 아니면 끝!" 류 긴급·압박 메시지 지양 [S6].
4. **구독 규칙** [S9] — 혜택은 구독 기간 내 회수 금지, 다른 플랫폼 결제 유도 금지, 결제 후 추가 조건(SNS 공유 등) 금지. 등급형(Bronze/Silver/Gold 상호배타) 구독은 현재 불가.
5. **서드파티 모델 백도어** — Creator Store 무료 모델에 숨은 스크립트(백도어). 공식 문서가 샌드박스·Capabilities 제한을 권고 [S23]. Cubika에서도 실제로 발견(11 문서). → 08 문서 보안 규칙.
6. **결제 기록** — Roblox는 구매 기록을 자동 저장하지 않음. `ProcessReceipt`는 멱등 처리 + DataStore 기록 필수 [S6].
