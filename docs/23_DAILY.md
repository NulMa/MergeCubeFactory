# 23. 접속 선물·일일 퀘스트 (2026-10-19)

> 사용자 요청: "접속보상은 확률성으로 / 15, 30, 45, 60분은 훔치기나 잼, 골든 큐브, 적은 양의 잼이 랜덤으로 / 3분 간격 보상은 적은 양의 돈이나 낮은 확률로 훔치기나 골든큐브 / 잼 보상도 줄이는 쪽으로".
> 모두 **무료** 랜덤이다(유료 랜덤 금지 규칙과 무관). 규칙 `shared/Daily.luau`, 서버 `server/Daily.luau`, 화면 `client/DailyUi.luau`, 테스트 `tests/Daily.spec.luau`.

## 1. 하루
- UTC 날짜 기준. 날짜가 바뀌면 오늘 플레이 시간·받은 선물·퀘스트가 새로 시작한다(`data.daily`).
- "오늘 플레이 시간"은 서버 secondTick마다 1초씩 쌓인다(접속해 있는 동안만).

## 2. 접속 선물 (눌러서 받기)
| 종류 | 언제 | 보상 (확률) |
|---|---|---|
| QUICK GIFT | 오늘 플레이 3분마다 1개, 하루 최대 20개(60분) — 안 받으면 쌓임 | 현금 = 초당 수입 × 20초(최소 $50) 90% / 훔치기 +1 5% / 황금 큐브 5% |
| PLAY GIFT | 오늘 플레이 15·30·45·60분 | 훔치기 +2 35% / 황금 큐브 30% / 젬 3 25% / 젬 8 10% |
- 황금 큐브 보상은 트레이에 황금 큐브를 하나 더 떨어뜨린다(`Events.gift`). 잡아야 보상(기존 황금 큐브 보상표). 선물 황금 큐브는 원래 자연 등장 시각을 늦추지 않는다.
- 훔치기 보상은 `stealPaid`(상한 없는 저장 횟수)에 더한다.

## 3. 일일 퀘스트
- 날짜 시드로 모든 서버가 같은 3개(Park–Miller, `Daily.questsFor`). 후보: 합치기 300 / 손으로 투하 60 / 배트로 큐브 치기 40 / 업그레이드 8 / 코어 부화 2 / 황금 큐브 2 / 변이 큐브 5.
- 하나 끝낼 때마다 눌러서 젬 2 + 현금(초당 수입 × 60초), 셋 다 끝내면 보너스 젬 5.
- 2026-10-20: 합치기·배트·업그레이드·변이 퀘스트는 목표가 진척에 따라 커진다: 목표 × (1 + 0.35 × 리버스 수, 최대 10회분 → ×4.5). 목표는 그날 퀘스트가 생길 때 정해 둔다(`Daily.questTarget`).

## 4. 젬 양
- 하루 최대: 큰 선물이 전부 젬 8이어도 32 + 퀘스트 11 = 43. 기댓값은 큰 선물 4 × (0.25×3 + 0.1×8) ≈ 6.2 + 퀘스트 11 ≈ **하루 17◆**. 꾸미기(100~150◆)는 1~2주 거리.

## 5. 화면
- 도감 버튼 아래 `DAILY` 버튼: 받을 게 있으면 금색 테두리 깜빡임 + 개수 배지, 없으면 다음 선물까지 남은 시간.
- 위 가운데 목표 바 힌트에 "PLAY GIFT READY" / "QUICK GIFT xN READY" / "QUEST DONE" (누르면 패널).

## 6. 7일 출석 (2026-10-20 "재방문 장치")
- 접속한 날마다 한 칸(빠진 날이 있어도 초기화하지 않음), 7일째 다음은 1일째. 보상은 **고정**(랜덤 없음), 눌러서 받기.

| 날 | 보상 |
|---|---|
| 1 | 현금 = 기본 수입 × 5분 |
| 2 | 펫 조각 = 최고 등급 합치기 40번치 |
| 3 | 젬 3 |
| 4 | 훔치기 +2 |
| 5 | 현금 = 기본 수입 × 15분 |
| 6 | 젬 5 |
| 7 | 보스 코인 10 + 젬 8 |

- 화면: 받을 칸이 있으면 접속 2초 뒤 7-DAY LOGIN 창(보스 레이드 참여 창이 떠 있으면 그 뒤에). DAILY 패널 머리의 `7-DAY` 버튼으로 다시 열기. `client/LoginUi.luau`, 서버 `Daily.claimLogin`.
